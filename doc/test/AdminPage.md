# AdminPage 測試案例

> 狀態：初始為 [ ]、完成為 [x]
> 注意：狀態只能在測試通過後由流程更新。
> 測試類型：前端元素、使用者互動、權限顯示

---

## [x] 【前端元素】應正確渲染管理後台頁面標題與返回連結
**範例輸入**：無（頁面初始載入）
**期待輸出**：顯示「🛠️ 管理後台」標題、「← 返回」連結指向 `/dashboard`

---

## [x] 【前端元素】應顯示管理員專屬頁面說明區塊
**範例輸入**：無（頁面初始載入）
**期待輸出**：顯示「管理員專屬頁面」、「只有 admin 角色可以訪問」、「user 角色會被重定向」、「受路由守衛保護」

---

## [x] 【前端元素】應顯示登出按鈕
**範例輸入**：無（頁面初始載入）
**期待輸出**：顯示「登出」按鈕

---

## [x] 【權限顯示】admin 角色應顯示「管理員」角色標籤
**範例輸入**：`user.role` = `'admin'`
**期待輸出**：顯示「管理員」角色標籤

---

## [x] 【權限顯示】user 角色應顯示「一般用戶」角色標籤
**範例輸入**：`user.role` = `'user'`
**期待輸出**：顯示「一般用戶」角色標籤

---

## [x] 【使用者互動】點擊登出按鈕應呼叫 logout 並導航到 /login
**範例輸入**：點擊「登出」按鈕
**期待輸出**：`logout()` 被呼叫，`navigate('/login', { replace: true, state: null })` 被呼叫
