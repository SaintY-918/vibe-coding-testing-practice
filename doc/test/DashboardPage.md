**範例輸入**：`user.username` = `'dean'`
**期待輸出**：顯示「Welcome, dean 👋」

---

## [x] 【前端元素】應顯示使用者頭像首字母大寫
**範例輸入**：`user.username` = `'dean'`

---

## [x] 【前端元素】應顯示登出按鈕
**範例輸入**：無（頁面初始載入）
**期待輸出**：顯示「登出」按鈕

---

## [x] 【前端元素】應顯示商品列表標題
**範例輸入**：無（頁面初始載入）
**期待輸出**：顯示「商品列表」

---

## [x] 【權限顯示】admin 角色應顯示「管理員」標籤和管理後台連結
**範例輸入**：`user.role` = `'admin'`
**期待輸出**：顯示「管理員」角色標籤、顯示「🛠️ 管理後台」連結指向 `/admin`

---

## [x] 【權限顯示】user 角色應顯示「一般用戶」標籤且不顯示管理後台連結
**範例輸入**：`user.role` = `'user'`
**期待輸出**：顯示「一般用戶」角色標籤、不顯示「管理後台」連結

---

## [x] 【Mock API】載入中應顯示 loading 狀態
**範例輸入**：API 尚未回應
**期待輸出**：顯示「載入商品中...」與 loading spinner

---

## [x] 【Mock API】載入成功應顯示商品卡片
**範例輸入**：MSW 回傳商品列表（筆記型電腦、無線滑鼠、機械鍵盤）
**期待輸出**：顯示 3 張商品卡片，包含名稱、價格、描述

---

## [x] 【Mock API】載入失敗應顯示 API 錯誤訊息
**範例輸入**：MSW 回傳 500 `{ message: '伺服器錯誤，請稍後再試' }`
**期待輸出**：顯示「伺服器錯誤，請稍後再試」

---

## [x] 【Mock API】載入失敗且無 message 時應顯示預設錯誤訊息
**範例輸入**：MSW 回傳 500（無 message 欄位）
**期待輸出**：顯示「無法載入商品資料」

---

## [x] 【使用者互動】點擊登出按鈕應呼叫 logout 並導航到 /login
**範例輸入**：點擊「登出」按鈕
**期待輸出**：`logout()` 被呼叫，`navigate('/login', { replace: true, state: null })` 被呼叫
